Settings & Integration

How to get a Google Client ID:
  1. Go to the Google Cloud Console.
  2. Create a project and go to the API Library to enable the Google Tasks API.
  3. Set up your OAuth Consent Screen (External) and add scope `.../auth/tasks`.
  4. Go to Credentials, click Create Credentials → OAuth Client ID.
  5. Select Web Application as the application type.
  6. Add http://localhost or the matching origin URL to Authorized JavaScript origins.
  7. Copy your Client ID and paste it above!
